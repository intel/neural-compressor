neural_compressor.torch.export.compressed_tensors

Pack fake-quantized linear layers into compressed-tensors / vLLM layout.

This module bridges neural_compressor.torch.algorithms.fake_quant and compressed-tensors (>= 0.9) / vLLM (>= 0.8) without requiring either inference package to be installed in the training environment:

  • mxfp4 -> mxfp4-pack-quantized: weight_packed (uint8 [out, in // 2]) + weight_scale (uint8 [out, in // 32] E8M0).

  • nvfp4 -> nvfp4-pack-quantized: weight_packed (uint8 [out, in // 2]) + weight_scale (float8_e4m3fn [out, in // 16]) + weight_global_scale (float32 [1] divisor 1 / global_scale) + optional input_global_scale (float32 [1] divisor (6 * 448) / input_amax).

  • mxfp8 -> mxfp8-quantized: weight (float8_e4m3fn [out, in]) + weight_scale (uint8 [out, in // 32] E8M0).

  • fp8_e4m3 -> float-quantized: weight (float8_e4m3fn [out, in]) + weight_scale (float32 [1]) + optional static input_scale (float32 [1]).

Pack a single linear module’s weight/bias/scales into compressed-tensors keys.

Parameters:

  • module_name – Logical module path inside the model (used for diagnostics).

  • weight – Dense weight tensor [out_features, in_features] (already LoRA-merged if needed).

  • bias – Optional dense bias tensor [out_features].

  • weight_quantizer – Module’s weight_quantizer.

  • input_quantizer – Optional module’s input_quantizer.

  • tensor_prefix – Optional target key prefix (defaults to module_name).

  • dtype – Dense fallback dtype for unquantized/bias tensors.

Returns:

(tensors_dict, scheme_spec) where scheme_spec is None when the layer is unquantized (e.g. bf16 or disabled weight_quantizer).
