Export an in-memory QAT/QAD model or saved checkpoint/adapter directory to HuggingFace format.

Supports all four workflows with bounded host memory: 1. In-memory QuantLinear / QuantLoraLinear / PreTrainedModel; 2. Saved full QAT/QAD checkpoint directory (model.safetensors + quantizer_state.json); 3. Saved PEFT LoRA adapter directory (streaming merge W + scaling * B @ A with base_model_path); 4. Multimodal VLM text-tower surgery when base_model_path is a VLM checkpoint and keep_vision=True.
