neural_compressor.torch.distillation.seq_packing.pack_sft_sequences(samples: Iterable[Mapping[str, Any]], seq_length: int, *, pad_token_id: int = 0, drop_tail: bool = False) → list[dict[str, torch.Tensor]][source]

Pack variable-length tokenized SFT samples into seq_length bins without cross-document RoPE bleed.

Each packed document receives reset position_ids starting from 0 ([0..L1-1, 0..L2-1, ...]), enabling HuggingFace flash_attention_2 varlen boundary detection while masking prompt/padding tokens via loss_mask and labels (-100).
