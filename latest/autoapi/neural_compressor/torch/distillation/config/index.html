class neural_compressor.torch.distillation.config.DistillationConfig(teacher: Any | None = None, loss: str = 'topk_kl', top_k: int = 4096, temperature: float = 1.0, reverse: bool = False, kd_weight: float = 1.0, ce_weight: float = 0.0, chunk_size: int = 1024, teacher_device: str = 'shard', offline_topk_dir: str | None = None, *, chunk: int | None = None)[source]

Teacher placement and divergence loss configuration for KDTrainer and QADTrainer.

teacher[source]

Teacher model specification: None, "self" (zero-VRAM LoRA self-teacher), a HuggingFace model path/ID string, or a pre-loaded torch.nn.Module.

loss[source]

"topk_kl" (default, ModelOpt-aligned), "kl" (full-vocab KL), or "ce".

top_k[source]

Number of highest-logit teacher vocabulary entries retained per token.

temperature[source]

Logit temperature (applied without any T^2 multiplier, matching ModelOpt).

reverse[source]

Swap (student_topk, teacher_topk) after gathering on teacher Top-K indices.

kd_weight[source]

Scalar multiplier on the knowledge-distillation term.

ce_weight[source]

Scalar multiplier on the next-token Cross-Entropy term (requires labels).

chunk_size[source]

Sequence token chunk size for memory-bounded lm_head projection (0 = unchunked).

teacher_device[source]

"shard" (FSDP2 sharded), "cuda" (replicated GPU), "cpu" (offloaded), "self" (in-place adapter/fake-quant toggle), or "offline" (precomputed Top-K shards).

offline_topk_dir[source]

Optional directory containing precomputed teacher Top-K shards.
