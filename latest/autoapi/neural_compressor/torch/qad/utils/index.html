neural_compressor.torch.qad.utils

QAD training utilities: throughput/memory metrics, callbacks, and FSDP2 layer discovery.

All FLOPs/MFU numbers report their basis (peak table, per-device vs cluster). Unknown devices return mfu=None instead of a made-up denominator.

Return decoder block class names for fsdp_config["transformer_layer_cls_to_wrap"].

Discovers actual decoder layer classes (including hybrid GatedDeltaNet + Attention or MoE blocks) directly from model while walking PeftModel / VLM / DDP wrappers, falling back to HuggingFace _no_split_modules when available.

neural_compressor.torch.qad.utils.teacher_placement(model: torch.nn.Module) → str[source]

Return a suggested teacher placement for model.

Models under 8B parameters default to the active local accelerator (e.g. "cuda" / "xpu"); larger models (such as a 27B teacher alongside a 27B student) default to FSDP2 "shard".
