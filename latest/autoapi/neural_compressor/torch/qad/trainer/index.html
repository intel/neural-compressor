Unified Quantization-Aware Distillation Trainer composing KDTrainer and QATTrainer.

MRO: QADTrainer -> KDTrainer -> QATTrainer -> transformers.Trainer * KDTrainer.compute_loss provides chunked zero-logit-allocation Top-K KL / Full KL / Hybrid CE

across online external teacher, zero-VRAM LoRA teacher_model="self", and offline Top-K shards.

  • QATTrainer provides prepare_qat, automatic static amax calibration, FSDP2 + PEFT checkpoint gathering, and lossless quantizer_state.json + quant_config.json persistence.
