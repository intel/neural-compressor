Calibrate all enabled static TensorQuantizer modules in model.

Provide either calib_fn(model) or dataloader (optionally bounded by num_batches). Enabled dynamic quantizers are temporarily bypassed during the calibration forward pass (matching ModelOpt enable_stats_collection) so static activation quantizers observe clean reference activations, then re-enabled upon completion. Static weight quantizers are also observed directly so MoE experts unvisited by small calibration sets still acquire valid weight amax buffers.
