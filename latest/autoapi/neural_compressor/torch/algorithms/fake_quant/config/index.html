Configuration for a single tensor quantizer (weights, inputs, or outputs).

Parameters:

  • format – Format name ("mxfp4", "nvfp4", "mxfp8", "fp8_e4m3", "bf16") or QuantFormat.

  • dynamic – Compute scale factors dynamically per forward tensor (True) or use a calibrated per-tensor amax buffer (False).

  • enabled – Master switch; False makes the quantizer an identity pass-through.

  • observer – Calibration observer for static quantization ("max" or "minmax").

  • backend – QDQ execution backend ("auto", "pytorch", or "triton").

  • amax – Optional pre-calibrated static maximum absolute value.

  • scheme – Optional alias ("dynamic" or "static") overriding dynamic.

class neural_compressor.torch.algorithms.fake_quant.config.QuantSchemeRule[source]

Declarative rule mapping target modules to weight/activation quantizer specs.

Target patterns follow compressed-tensors / ModelOpt conventions: * Class name: "Linear" matches supported linear module types. * Regex (prefixed with "re:"): "re:.*mlp\.(gate|up|down)_proj$" (full-string match). * Shell glob: "*mlp.experts*" (matched via fnmatch.fnmatchcase()). * Exact or suffix module name: "lm_head" matches "lm_head" or "*.lm_head".

When multiple rules in FakeQuantConfig.config_groups match a module, later rules override earlier rules.

class neural_compressor.torch.algorithms.fake_quant.config.FakeQuantConfig(config_groups: Sequence[QuantSchemeRule | dict[str, Any]] | None = None, ignore: Sequence[str] | None = None, quantizer_state_path: str | pathlib.Path | None = None, backend: neural_compressor.torch.algorithms.fake_quant.functional.QuantBackendName = 'auto', white_list: list[str | Callable] | None = DEFAULT_WHITE_LIST)[source]

Top-level INC configuration for fake-quantization (QAT / QAD / PTQ simulation).

Integrates directly with neural_compressor.torch.quantization.prepare, quantize, prepare_qat, and convert.

Parameters:

  • config_groups – Ordered list of QuantSchemeRule entries. Defaults to MXFP4 dynamic weight + input quantization on all Linear modules.

  • ignore – Module patterns excluded from quantization (checked before config_groups). Defaults to ["lm_head", "re:.*embed.*"].

  • quantizer_state_path – Optional JSON file containing calibrated static amax values.

  • backend – Default QDQ execution backend ("auto", "pytorch", or "triton").
