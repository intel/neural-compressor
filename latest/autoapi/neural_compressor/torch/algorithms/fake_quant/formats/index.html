neural_compressor.torch.algorithms.fake_quant.formats

Quantization format specs shared by QAT and QAD.

A format is a first-class object instead of ModelOpt’s num_bits=(E, M) tuple: recipes and code both speak "mxfp4" / "fp8_e4m3", and every property the quantizer needs (block size, scale kind, element range) is explicit.
