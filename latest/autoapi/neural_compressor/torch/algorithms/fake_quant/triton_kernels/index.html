neural_compressor.torch.algorithms.fake_quant.triton_kernels

Fused single-pass Triton QDQ kernels for MXFP4, NVFP4, MXFP8, and FP8 E4M3.

Key properties: 1. 0-ULP bit-level parity with functional.py ("pytorch" backend) and

NVIDIA ModelOpt CUDA kernels across random, boundary, midpoint, zero, and subnormal inputs by using IEEE-754 tl.div_rn, NVIDIA libdevice log2/ceil/exp2, and exact register-predicated E2M1 round-to-even.

  1. Zero intermediate global memory buffers: block-wise amax, E8M0 / E4M3 scale quantization, E2M1 / E4M3 element rounding, and rescaling all execute in registers within a single kernel pass (1 global read + 1 global write).

  2. 64-bit pointer safety: supports activations exceeding 2**31 elements (e.g., [B, 8192, 17408] on 27B+ models) without 32-bit index overflow.
