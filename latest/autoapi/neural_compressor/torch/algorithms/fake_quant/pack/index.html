neural_compressor.torch.algorithms.fake_quant.pack

Cold-path weight bit-packing and dequantization utilities for checkpoint export.

This module is strictly separated from functional so nibble packing/unpacking never executes during QAT/QAD training forward or activation recomputation. Packed layouts follow compressed-tensors and vLLM conventions:

  • MXFP4: data uint8 [out, in // 2] (low nibble = even column), scale uint8 E8M0 [out, in // 32] (exponent + 127).

  • NVFP4: data uint8 [out, in // 2], scale float8_e4m3fn [out, in // 16], global_scale float32 [1].

  • MXFP8: data float8_e4m3fn [out, in], scale uint8 E8M0 [out, in // 32].

  • Static FP8 E4M3: data float8_e4m3fn [out, in], scale float32 [1] (computed via exact dual-FP32 reciprocal 1 / (448 / amax) so dequantization is 0-ULP identical to training QDQ).
