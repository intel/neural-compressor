neural_compressor.jax.algorithms.smooth_quant

SmoothQuant for JAX/Keras models, applied by folding (no extra ops at inference).

SmoothQuant (Xiao et al., 2023) migrates activation outliers into the weights. For a matmul y = x @ W and a per-input-channel factor s:

y = (x / s) @ (diag(s) W),    s_j = max|x_j| ** alpha / max|W_j| ** (1 - alpha)

The division x / s is folded into the layer that produces x (a normalization gain or the output channels of a previous linear layer), so the smoothed model computes the same function with the same graph, and quantizing it gives the same kernels and speed as quantizing the original model.

Which layers can be folded depends on the model’s data flow, so the foldable groups are described per decoder-block class in SMOOTH_RULES. Gemma3 decoder blocks are supported; other models are left unchanged (with a warning).

class neural_compressor.jax.algorithms.smooth_quant.ChannelAbsMaxObserver(channel_shape: Tuple[int, Ellipsis], **kwargs)[source]

Calibration observer: running per-channel maximum of |x| over all but the last num_channel_dims axes.

The statistic is a non-trainable variable, so it is updated inside a jitted, stateless calibration function (e.g. the CausalLM generate function used during quantization) like the other INC observers. Input autocasting is disabled, so the observed layer receives its input unchanged (same dtype) during calibration.

class neural_compressor.jax.algorithms.smooth_quant.SmoothGroup[source]

Consumers sharing one input, the layer whose input is observed, and how 1 / s is folded.

head_repeat > 1 means the consumer input channels are (n_q, h) while the absorbing layer produces (n_kv, h) with n_q = n_kv * head_repeat (grouped-query attention); one factor per kv channel is shared by the query heads of its group.

absorb(s) folds 1 / s into the producing layer and returns the factors that the stored (possibly bfloat16-rounded) weights actually implement; the consumers are scaled by those, so the fold stays exact.

neural_compressor.jax.algorithms.smooth_quant.gemma3_decoder_block_groups(block) → List[SmoothGroup][source]

Foldable groups of a keras-hub Gemma3DecoderBlock.

  • q/k/v projections, input = pre_attention_norm output -> fold into that norm

  • gate/up projections, input = pre_ffw_norm output -> fold into that norm

  • down projection, input = gelu(gate) * up -> fold into the up projection output channels

  • attention output projection, input = softmax(qk) @ v -> fold into the value projection output channels (shared by the query heads of each kv head)

neural_compressor.jax.algorithms.smooth_quant.apply_smooth_quant(model: keras.Model, calib_function: Callable, alpha: float = 0.5, layer_settings: LayerSettings | None = None) → None[source]

Smooth the model in place: calibrate per-channel activation ranges, then fold the factors into the weights.

Only blocks with a rule in SMOOTH_RULES are smoothed (Gemma3 decoder blocks); for other models a warning is logged and nothing is run (no calibration pass).

Parameters:

  • model (keras.Model) – FP32/BF16 model (not yet quantized), modified in place.

  • calib_function (Callable) – Runs calibration data through the model (the static-quantization calib function).

  • alpha (float) – Migration strength in [0, 1] (0.5 balances activation and weight ranges), used for all groups when layer_settings is not given.

  • layer_settings (Callable, optional) – Per-layer settings from the quantization configs, see LayerSettings.
