.. py:function:: export_hf_checkpoint(model_or_checkpoint: Union[torch.nn.Module, str, pathlib.Path], output_dir: Union[str, pathlib.Path], *, export_format: ExportFormat = 'compressed_tensors', quant_config: Optional[neural_compressor.torch.algorithms.fake_quant.FakeQuantConfig] = None, quant_state_path: Optional[Union[str, pathlib.Path]] = None, base_model_path: Optional[Union[str, pathlib.Path]] = None, tokenizer: Any = None, keep_vision: bool = True, vlm_target_prefix: str = 'model.language_model.', max_shard_size: str = '5GB', dtype: torch.dtype = torch.bfloat16, copy_tokenizer_and_processor: bool = True) -> pathlib.Path

   Export an in-memory QAT/QAD model or saved checkpoint/adapter directory to HuggingFace format.

   Supports all four workflows with bounded host memory:
   1. In-memory ``QuantLinear`` / ``QuantLoraLinear`` / ``PreTrainedModel``;
   2. Saved full QAT/QAD checkpoint directory (``model.safetensors`` + ``quantizer_state.json``);
   3. Saved PEFT LoRA adapter directory (streaming merge ``W + scaling * B @ A`` with ``base_model_path``);
   4. Multimodal VLM text-tower surgery when ``base_model_path`` is a VLM checkpoint and ``keep_vision=True``.
