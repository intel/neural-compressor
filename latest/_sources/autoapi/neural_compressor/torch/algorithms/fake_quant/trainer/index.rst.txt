.. py:function:: ensure_peft_gradient_checkpointing_delegation(model: torch.nn.Module) -> None

   Ensure ``PeftModel`` delegates gradient checkpointing and preserves adapter gradients under FSDP2 AC.

   Besides forwarding ``gradient_checkpointing_enable`` / ``disable`` to the inner backbone, this
   registers an idempotent forward hook on the input embedding module that marks its output
   ``requires_grad_(True)`` whenever ``torch.is_grad_enabled()`` is ``True``. Without this hook,
   FSDP2 ``activation_checkpointing: true`` (which wraps decoder layers in reentrant
   ``checkpoint_wrapper`` without calling ``Trainer.gradient_checkpointing_enable``) receives
   ``requires_grad=False`` hidden states from frozen base embeddings and drops adapter gradients.

.. py:class:: QATTrainer(model: Union[torch.nn.Module, Any] = None, args: Any = None, *pos_args, quant_config: Optional[neural_compressor.torch.algorithms.fake_quant.config.FakeQuantConfig] = None, calib_batches: int = 0, quantizer_state_path: Optional[Union[str, pathlib.Path]] = None, **kwargs)



   HuggingFace ``Trainer`` extended with fake-quantization preparation, static ``amax`` calibration,
   and lossless ``quantizer_state.json`` checkpointing (including FSDP2 + PEFT support).

   Usable standalone for standard SFT / CausalLM Cross-Entropy QAT without any teacher model,
   and composed with :class:`~neural_compressor.torch.distillation.KDTrainer` to form
   :class:`~neural_compressor.torch.qad.QADTrainer`.
