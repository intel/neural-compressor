   Can be used either as a decorator ``@register_quant_module(nn.Linear)`` or a direct function call
   ``register_quant_module(LoraLinear, QuantLoraLinear.from_lora)``.

.. py:function:: fake_quant_entry(model: torch.nn.Module, configs_mapping, mode: neural_compressor.common.utils.Mode = Mode.QUANTIZE, run_fn=None, run_args: Any = None, **kwargs) -> torch.nn.Module

   Replace modules with fake-quant subclasses and optionally calibrate.

   :param model: Float model, modified in place.
   :param configs_mapping: ``{(module_name, op_type): ModuleQuantConfig}`` from
                           :meth:`FakeQuantConfig.to_config_mapping`.
   :param mode: ``PREPARE`` inserts quantizers only; ``QUANTIZE`` also calibrates
                static quantizers when ``run_fn`` is given; ``CONVERT`` finalizes
                calibration without replacing the fake-quant modules.
   :param run_fn: Calibration forward loop, called as ``run_fn(model, *run_args)``.
   :param run_args: Positional arguments for ``run_fn``.
