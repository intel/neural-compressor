.. py:function:: is_fp8_kv_cache_enabled_by_env() -> bool

   Check whether FP8 KV cache is enabled by the ``INC_JAX_FP8_KV_CACHE`` environment variable.

   FP8 KV cache is disabled by default; set the variable to ``1``, ``true``, ``yes`` or ``on`` to enable it.
   The variable is read once per process; call ``is_fp8_kv_cache_enabled_by_env.cache_clear()`` to re-read it.

   :returns: True if FP8 KV cache is enabled.
   :rtype: bool


.. py:function:: select_kv_cache_dtype(layer, default_dtype)

   Select the KV-cache dtype of a decoder layer and disable autocasting for FP8 caches.

   FP8 is selected only when ``layer.attention.can_use_fp8_kv_cache()`` returns True.
   In that case input autocasting is disabled on ``layer`` and ``layer.attention``,
   since Keras would otherwise upcast the FP8 cache to the compute dtype.
   Other layers are left unchanged and use ``default_dtype``.

   :param layer: Decoder layer with an ``attention`` sublayer.
   :type layer: keras.layers.Layer
   :param default_dtype: Cache dtype for layers without an FP8 cache.
   :type default_dtype: str | jnp.dtype

   :returns: KV-cache dtype for the layer.
   :rtype: str | jnp.dtype


.. py:function:: causal_lm_make_replace_build_cache(self)

   Replace _build_cache to allocate KV caches using each attention layer's dtype.

   The cache dtype and autocasting are decided at cache allocation
   (see ``select_kv_cache_dtype``). Any cached ``generate_function`` is
   invalidated so the next ``generate()`` call traces the new cache path.

   :param self: Causal language model instance to modify.
   :type self: keras.Model
